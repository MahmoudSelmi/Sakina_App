# صور القراء

الـ API المستخدم في التطبيق (mp3quran.net) مبيوفرش صور رسمية للقراء.

لو حابب تحط صورة حقيقية لشيخ معين، حط ملف صورة هنا بالاسم ده:

    assets/reciters/{id}.jpg

فين تلاقي رقم الـ id؟ هو نفس الرقم اللي راجع من الـ API لكل قارئ (نفس القيمة
اللي بيتبنى عليها `reciter.id` في الكود). ظاهر بسهولة لو عملت print للقيمة
أو من رابط الـ API مباشرة: https://www.mp3quran.net/api/v3/reciters?language=ar

التطبيق بيدور تلقائيًا على `assets/reciters/{id}.jpg`، ولو مش لاقيها بيرجع
للأفاتار المصمم (تدرج لوني + حرف) من غير ما يعمل كراش.
